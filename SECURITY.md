# Security

## Support posture

This repository is a public proof surface and does not accept live patient, clinician, assay, or tenant data.

## Scope

- synthetic diagnostics and QC evidence only
- read-only public demonstration routes
- no production credentials, API keys, or tenant secrets in the repository

## Disclosure notes

- do not describe this repo as HIPAA compliant, CLIA compliant, CAP accredited, or FDA cleared
- use language such as `evidence posture`, `readiness`, `routing`, and `review surface`
- any real deployment handling regulated data would require separate security, privacy, and legal review

## Reporting

If you identify a security issue in the public code, open a private disclosure through GitHub security advisories or contact the maintainer directly before public disclosure.
